# Daftar

*The journal you actually own.* A lamplit journaling app: write offline, every word exports as readable JSON.

This is a personal project in development. It is **not open source**: all rights reserved, no licence is granted to copy, host or redistribute it. Reading the code is welcome.

Developer notes live in [CLAUDE.md](CLAUDE.md); database setup in [supabase/README.md](supabase/README.md).

```
cd app && npm install && npm run dev      # then open http://localhost:5173/?preview=1 for sample data
```
